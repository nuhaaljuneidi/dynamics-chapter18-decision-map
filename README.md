# Chapter 18: Planar Dynamics of Rigid Bodies Decision Map

An interactive decision map for selecting a solution strategy for rigid-body kinetics problems from Bedford and Fowler's *Engineering Mechanics: Dynamics*, Chapter 18.

Developed by **Dr. Nuha Aljuneidi** for engineering education and independent study.

## Learning purpose

The map connects the free-body and kinetic diagrams to the planar equations of motion and guides students through moments of inertia, translation (slide or tip), rotation about a fixed axis, and general plane motion, including rolling with and without slipping.

## Use locally

Open `index.html` in a modern browser. The tool uses plain HTML, CSS, and JavaScript and requires no build process.
